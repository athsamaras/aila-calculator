# AILA calculator

Web calculator and study site for AILA (AILA-Admission, AILA-Discharge, AILA-Max): predicted risk of death following hospitalisation in a cardiology department, with setting-specific baselines (Greece, London, Amsterdam, Hamburg), a custom local baseline, and risk-group output where no baseline is available. Pages: Calculator, About, Study Network, Evidence, Contact.

Live: https://athsamaras.github.io/aila-calculator/

The previous version (v1.8, with the what-if simulator) is in the commit history (32ffc72).
