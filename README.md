# GRIXA risk calculator

Web calculator and study site for **GRIXA** (Graded Risk model, Internationally validated, eXplainable All-cause mortality prediction): predicted risk of death following hospitalisation in a cardiology department.

GRIXA comprises three nested models that use progressively broader predictor sets: **GRIXA-Core** (seven predictors at or near admission), **GRIXA-Dis** (adds four discharge predictors) and **GRIXA-Bio** (adds four further blood tests).

The calculator offers setting-specific baselines (Greece, London, Amsterdam, Hamburg), a custom local baseline, and risk-group output where no baseline is available. All calculations run in the browser; no data are transmitted.

Live: https://cardiomining.github.io/grixa/

For research and education; not a medical device.
